Notifly API는 모든 요청에 대해 **인증 토큰(Authentication Token)** 이 필요합니다.  
토큰은 `POST /authenticate` 엔드포인트를 통해 발급받으실 수 있으며, 유효 기간은 **1시간**입니다.

<Info>
인증 토큰은 1시간 후 만료되며, 만료 시 `401 Unauthorized` 오류가 반환됩니다.  
안전한 요청을 위해 토큰은 매 호출 시 재발급받으시는 것을 권장드립니다.
</Info>

<Note>
클라이언트 애플리케이션에서는 Access/Secret Key를 **직접 노출하지 않도록 주의해 주세요**.
</Note>

### Headers

<ParamField header="Content-Type" type="string" required placeholder="application/json">
  요청 본문의 MIME Type을 지정해주세요
</ParamField>

### Request Body Parameters

<ParamField body="accessKey" type="string" required placeholder="example1234567890abcdef1234567890ab">
  Notifly 프로젝트 설정 페이지에서 확인하실 수 있습니다. 각 프로젝트별로 1개의 Access Key가 존재합니다.
</ParamField>

<ParamField body="secretKey" type="string" required placeholder="EXAMPLEabc9%">
  Notifly 프로젝트 설정 페이지에서 확인하실 수 있습니다. 각 프로젝트별로 1개의 Secret Key가 존재합니다.
</ParamField>

<ResponseExample>

```json 200 Success
{
  "data": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example",
  "error": null
}
```

```json 400 Bad Request

  "code": 400,
  "error": "Bad request: missing key"
}
```

```json 401 Unauthorized
{
  "code": 401,
  "error": "Unauthorized: invalid key"
}
```

```json 500 Internal Server Error
{

  "error": "Internal Server Error"
```

</ResponseExample>


### 문의

Access Key와 Secret Key 관련 문의사항이 있으시면 **contact@notifly.tech**로 연락해 주시기 바랍니다.
