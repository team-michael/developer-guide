title: "Notifly MCP 서버"
---

Notifly MCP 서버는 대규모 언어 모델(LLM)이 외부 도구와 데이터 소스와 상호작용하도록 돕는 오픈 표준 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/)을 구현합니다.

Notifly를 연동하는 과정에서도 작업 흐름이 끊기지 않도록, 개발자에게 두 가지 핵심 도구를 제공합니다.

- **문서 검색 (Documentation Search)** — Notifly 문서 전반(사용자 가이드, API 레퍼런스, 문제 해결, 베스트 프랙티스)을 의미 기반 검색 기능으로 빠르게 찾아볼 수 있습니다.

- **SDK 검색 (SDK Search)** — Notifly SDK(iOS, Android, Flutter, React Native, JavaScript)와 Google Tag Manager 템플릿, 연동 예제를 한 번에 살펴볼 수 있습니다. 필요한 SDK 심볼(타입, 메서드, 파라미터)을 신속하게 찾아 실제 운영 환경에 바로 적용 가능한 코드 스니펫을 제공합니다.

## 통합 가이드

### 요구 사항

- Node.js 18 이상
- MCP 호환 클라이언트(예: Cursor, Visual Studio Code, Claude Code CLI, Codex CLI)

### 설치

<CodeGroup>

```bash npm
npm i -g notifly-mcp-server@latest
```

```bash yarn
yarn global add notifly-mcp-server@latest
```

</CodeGroup>

### .mcp.json 구성

프로젝트 루트(또는 사용하는 MCP 클라이언트의 설정 경로)에 `.mcp.json` 파일을 새로 만들거나 업데이트하세요.

아래는 `npx`를 사용하는 권장 구성입니다.

```json
{
  "mcpServers": {
    "notifly-mcp-server": {
      "command": "npx",
      "args": ["-y", "notifly-mcp-server@latest"]
    }
  }
}
```

### 주요 MCP 클라이언트에서 사용하기

<Tabs>

<Tab title="Android Studio">
  <p><strong>옵션 1: Android Studio용 GitHub Copilot 플러그인</strong></p>
  1. **파일**(macOS의 경우 **Android 스튜디오**) > **설정** > **플러그인** > **GitHub Copilot - Your AI Pair Programmer**를 선택해 GitHub Copilot 플러그인을 설치합니다.
  2. 같은 경로에서 **도구** > **GitHub Copilot** > **Model Context Protocol (MCP)** > **Configure**로 이동해 Notifly MCP 서버를 등록합니다.
  3. `mcp.json`에 Notifly MCP 서버 설정을 추가합니다.
  
  ```json
  {
    "mcpServers": {
      "notifly-mcp-server": {
        "command": "npx",
        "args": ["-y", "notifly-mcp-server@latest"]
      }
    }
  }
  ```

  <p><strong>옵션 2: JetBrains MCP 서버 플러그인 + 선호하는 MCP 클라이언트</strong></p>
  JetBrains MCP 서버를 프록시로 사용하면 Android Studio의 기능을 그대로 활용하면서도 익숙한 MCP 클라이언트에서 작업할 수 있습니다.
  1. **파일**(macOS의 경우 **Android 스튜디오**) > **설정** > **플러그인** > **MCP 플러그인**으로 이동해 JetBrains MCP 서버 플러그인을 설치합니다.
  2. 사용하는 MCP 클라이언트 설정에 Notifly MCP 서버와 JetBrains MCP 프록시 구성을 함께 추가합니다.
  ```json
  {
    "mcpServers": {
      "notifly-mcp-server": {
        "command": "npx",
        "args": ["-y", "notifly-mcp-server@latest"]
      },
      "jetbrains": {
        "command": "npx",
        "args": ["-y", "@jetbrains/mcp-proxy"]
      }
    }
  }
  ```
  3. Android Studio와 MCP 클라이언트를 동시에 실행한 뒤, MCP 클라이언트에서 프로젝트를 계속 진행합니다.

  <p><strong>옵션 3: Android Studio Agent의 Gemini</strong></p>
  <ol>
    <li>
      <a href="https://developer.android.com/studio/gemini/add-mcp-server" target="_blank" rel="noopener noreferrer">
        Android Studio의 Gemini에 MCP 서버를 추가합니다.
      </a>
    </li>
    <li>`mcp.json`에 Notifly MCP 서버 설정을 붙여넣습니다.</li>
  </ol>

  ```json
  {
    "mcpServers": {
      "notifly-mcp-server": {
        "command": "npx",
        "args": ["-y", "notifly-mcp-server@latest"]
      }
    }
  }
  ```

### 소스에서 빌드 (선택 사항)

소스 코드를 직접 빌드하거나 최신 개발 버전이 필요할 때는 다음 단계를 따르세요.

```bash
git clone https://github.com/notifly-tech/notifly-mcp-server
cd notifly-mcp-server
npm install
npm run build
```

이후에는 `.mcp.json`을 수정해 방금 빌드한 산출물을 참조하도록 설정합니다.

```json
{
  "mcpServers": {
    "notifly": {
      "command": "node",
      "args": ["/path/to/notifly-mcp-server/dist/index.js"]
    }
  }
}
```
