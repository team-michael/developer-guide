---

Notifly MCP Server는 대규모 언어 모델(LLM)이 외부 도구와 데이터 소스와 상호작용하도록 돕는 오픈 표준 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/)을 구현합니다.

Notifly를 연동하는 과정에서도 작업 흐름이 끊기지 않도록, 개발자에게 두 가지 핵심 도구를 제공합니다.

- **문서 검색 (Documentation Search)** — Notifly 문서 전반(사용자 가이드, API 레퍼런스, 문제 해결, 베스트 프랙티스)을 의미 기반 검색 기능으로 빠르게 찾아볼 수 있습니다.

- **SDK 검색 (SDK Search)** — Notifly SDK(iOS, Android, Flutter, React Native, JavaScript)와 Google Tag Manager 템플릿, 연동 예제를 한 번에 살펴볼 수 있습니다. 필요한 SDK 심볼(타입, 메서드, 파라미터)을 신속하게 찾아 실제 운영 환경에 바로 적용 가능한 코드 스니펫을 제공합니다.

## 통합 가이드

### 요구 사항

- Node.js 18 이상
- MCP 호환 클라이언트(예: Cursor, Visual Studio Code, Claude Code CLI, Codex CLI)

### 설치

<CodeGroup>

```bash npm
npm i -g notifly-mcp-server@latest
```

```bash yarn
yarn global add notifly-mcp-server@latest
```

</CodeGroup>

### .mcp.json 구성

프로젝트 루트(또는 사용하는 MCP 클라이언트의 설정 경로)에 `.mcp.json` 파일을 새로 만들거나 업데이트하세요.

아래는 `npx`를 사용하는 권장 구성입니다.

```json
{
  "mcpServers": {
    "notifly-mcp-server": {
      "command": "npx",
      "args": ["-y", "notifly-mcp-server@latest"]
    }
  }
}
```

### 소스에서 빌드 (선택 사항)

소스 코드를 직접 빌드하거나 최신 개발 버전이 필요할 때는 다음 단계를 따르세요.

```bash
git clone https://github.com/notifly-tech/notifly-mcp-server
cd notifly-mcp-server
npm install
npm run build
```

이후에는 `.mcp.json`을 수정해 방금 빌드한 산출물을 참조하도록 설정합니다.

```json
{
  "mcpServers": {
    "notifly": {
      "command": "node",
      "args": ["/path/to/notifly-mcp-server/dist/index.js"]
    }
  }
}
```
